# デジタルお箏

Chromebook のタッチ画面で弾ける13弦のお箏です。音楽の授業（中学生）向け。

- 曲と調弦は Google スプレッドシート「**デジタルお箏 曲と調弦**」で管理します。行を足すと曲が増えます。
- 生徒は Classroom に貼ったURLを開くだけ。インストールもログインの追加も不要です。
- 音は録音ではなく、ブラウザの中で弦の音を作っています（軽く、遅れが少ない）。

## 生徒の使い方

| したいこと | やり方 |
|---|---|
| 弦を弾く | **柱（ことじ）の右側**をタップ |
| かき鳴らす | 柱の右側を指でなでる（通った弦が順に鳴る） |
| 押し手（音を上げる） | **柱の左側**を左手で押さえたまま、右手で弾く。弾いた後に押すと音がのびながら上がる |
| 曲の練習 | 光っている弦を弾くと、楽譜の印が次へ進む |
| お手本を聞く | 「▶ お手本」。「速さ」でゆっくりにもできる |
| キーボードで弾く | Q W E R T Y U I O P @ [ ] が 一〜巾。Shift を押しながらで押し手 |

## 最初に1回だけ：ウェブアプリとして公開する

1. スプレッドシート「デジタルお箏 曲と調弦」を開き、メニューの **拡張機能 → Apps Script** を押す
2. `コード.gs` に最初から入っている文字をすべて消し、[`Code.gs`](Code.gs) の中身を貼り付ける
3. 左の「ファイル」の **＋ → HTML** を押し、名前を **`Index`** にする（`.html` は自動で付く）。中身をすべて消し、[`Index.html`](Index.html) の中身を貼り付ける
4. 💾（保存）を押す
5. 右上の **デプロイ → 新しいデプロイ**
   - ⚙ の「種類の選択」で **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校名）内の全員**
   - **デプロイ** を押し、アクセスの承認を求められたら自分のアカウントで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を Classroom に貼る

> Code.gs や Index.html を後で貼り替えたときは「デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ」。URL は変わりません。
> スプレッドシートの曲を直しただけなら、デプロイし直す必要はありません（生徒がページを開き直すと反映）。

## スプレッドシートの書き方

**「曲」シート**（1行＝1曲）

| 列 | 内容 |
|---|---|
| 表示 | チェックを外すと生徒の画面に出ない |
| 曲名 | 曲の名前 |
| 調弦 | 「調弦」シートの名前から選ぶ |
| 速さ（1分間の拍） | お手本の速さ（生徒が画面で変えられる） |
| 楽譜 | 下の書き方で |
| 歌詞 | 楽譜と同じ数だけ、スペースで区切る（のばす所は `ー`） |
| メモ | 曲名の横に出る |

**楽譜の書き方**

| 書き方 | 意味 |
|---|---|
| `一` 〜 `十` `斗` `為` `巾` | 弦の名前。1つで1拍 |
| `ー`（長音記号） | 前の音をのばす（1拍）。漢数字の「一」とまちがえないように |
| `○` | 休み（1拍） |
| `八七` | 1拍の中に2つの音（半分ずつ）。3つなら3等分 |
| `七押` / `七半押` | 押し手（全音／半音上げる） |
| `\|` または改行 | 小節の区切り |
| スペース | 拍の区切り（全角でもよい） |

例（さくらさくらの始まり）：`七 七 八 ー | 七 七 八 ー | 七 八 九 八 | 七 八七 六 ー`

**「調弦」シート**：13本の弦の音を `E4` `F#4` `Bb3` のように書く（`C4` が真ん中のド）。行を足すと調弦が増えます。

## 試すだけなら

`Index.html` をそのまま Chrome で開くと、見本の曲（さくらさくら、音階の練習）で動きます（スプレッドシートにはつながりません）。
