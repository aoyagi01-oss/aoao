# 画面配信（静止画）

先生の画面を **数秒ごとの静止画** にして、生徒の Chromebook のブラウザに映すしくみです。Google Meet や Zoom を使わずに、**Classroom に貼ったURLを開くだけ** で先生の画面が見られます。

- 生徒用：https://aoyagi01-oss.github.io/aoao/gamen-kyoyu/ （いつも同じURL。Classroom には最初に1回貼るだけ）
- 先生用：https://aoyagi01-oss.github.io/aoao/gamen-kyoyu/teacher.html

```
先生用ページ ──「配信開始」→ 画面が変わったときだけ画像を送る
      │
      ▼
Apps Script（先生の Google アカウント。画像は最大6時間で自動で消える）
      ▲
      │ 2秒ごとに「新しい画面はある？」と確かめる
生徒用ページ ── 開いておくだけで、新しい画面が自動で映る
```

- **画面が変わったときだけ送ります**。スライドをめくると、1〜3秒ほどで生徒の画面が切り替わります。マウスが動いただけでは送りません。
- 動画やアニメーションの表示には向きません（静止画なので）。
- 生徒は操作いりません。先生が配信を始める前に開いても「待っています」と出て、始まると自動で映ります。

## 先生の手順（授業ごと）

1. 先生用ページを開く（合言葉は2回目から自動で入ります）
2. **▶ 配信開始** を押して、見せたいものを選ぶ
   - スライドだけ見せる → 「タブ」または「ウィンドウ」
   - 何でも見せる → 「画面全体」
3. スライドを全画面で表示して、ふつうに授業をする
4. 終わったら **■ 終了**

| ボタン | はたらき |
|---|---|
| ⏸ 一時停止 | 生徒には今の画面が出たまま。その間に答えや別の画面を見られる |
| 📤 今すぐ送る | 書き込みなどの小さな変化は自動で送られないことがある。そのときに押す |
| ■ 終了 | 生徒には最後の画面が残り、「配信は止まっています」と出る |

> 先生用ページは **別のウィンドウ** で開いておくと安心です。下の「生徒に届いている画面」に、いま生徒に見えている画像が出ます。

## 生徒の見方

- 開いておくだけで、先生の画面が映ります。**⛶ 全画面** で画面いっぱいになります。
- **見たいところを手元で拡大できます**（先生の画面や、ほかの生徒の画面は変わりません）
  - 見たいところを **ダブルタップ**（ダブルクリック）→ 拡大。もう一度ダブルタップで元に戻る
  - **2本指で広げる・つまむ**（ピンチ）、マウスのホイール、左下の **＋ －** でも拡大・縮小できる
  - 拡大中は **ドラッグ** で見る場所を動かせる。**元の大きさ** ボタンで戻る
  - 先生がスライドをめくっても、拡大した位置はそのまま

## 最初に1回だけ：Apps Script を用意する

1. Google ドライブで **新規 → その他 → Google Apps Script** を押す（名前は「画面配信」など）
2. 最初から入っている文字をすべて消し、このフォルダの [`Code.gs`](Code.gs) の中身を貼り付ける
3. `const PASSWORD = 'ここを合言葉に変える';` の `ここを合言葉に変える` を、自分だけの合言葉に書き換える
4. 💾（保存）を押す
5. 右上の **デプロイ → 新しいデプロイ**
   - ⚙ の「種類の選択」で **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（選べない場合は、学校のドメイン内の全員）
   - **デプロイ** を押し、アクセスを許可する（「確認されていません」と出たら「詳細」→「（名前）に移動」→「許可」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーし、[`config.js`](config.js) の `API_URL = ''` の `''` の中に貼る

> `Code.gs` を後で変えたときは「デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。

## 気をつけること

- **最初は少人数で試してください**。Apps Script には同時に動ける数の上限（1アカウントで約30）があります。生徒は2秒ごとに確認するので、1クラス40人くらいまでが目安です。何クラスも同時に使うときは、先生ごとに自分の Apps Script を用意してください。
- 画像は先生の Google アカウントの一時保存場所（キャッシュ）に置かれ、**6時間で自動で消えます**。スプレッドシートやドライブには残りません。
- 生徒用URLを知っている人は画面を見られます（合言葉が要るのは配信する側だけ）。個人情報が映る画面は配信しないでください。見せたくないときは **⏸ 一時停止** を使います。
- 先生の画面を「画面全体」で配信すると、通知などもそのまま映ります。
