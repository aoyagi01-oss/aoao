# 資質・能力21 ふりかえりアプリ

総合的な探究の時間に、生徒が「探究的な学びを通じて身に付けたい資質・能力21」を自己評価するアプリです。回答は先生のスプレッドシートに集まり、メニューからクラス集計やレポートを作れます。

- `Index.html`：生徒が開く画面（Apps Script の HTML ファイル「Index」）。学校のピクトグラムを埋め込み済み
- `Report.html`：先生がレポートを作って印刷する画面（Apps Script の HTML ファイル「Report」）
- `Code.gs`：スプレッドシート側のプログラム（受け取り・名簿・集計・レポート作成）

先生向けの使い方は、Google ドキュメントの [資質・能力21 ふりかえりアプリ 先生用ガイド](https://docs.google.com/document/d/1z3n_FYeBq7Ci9SY0DjxlAJEnYoUaGRKntvX-mX8PfHY/edit) にまとめています。集約用スプレッドシートの先頭の「使い方」シートからも開けます。

## ほかの学校に渡す（配布版）

`dist/` フォルダは、ほかの学校に渡すための配布版です。`python3 tools/make_dist.py "学校名" "入力例の姓"` で作り直せます（いまは羽咋高校用）。もとのコードとのちがいは次のとおりです。

- 生徒画面の上の学校名と、氏名の入力例（「羽咋　太郎」など）を、その学校のものにしています
- フィードバックの「錦丘高校が目指す」という言葉を外しています（目標の文はそのまま）
- 錦丘のピクトグラムを外しています。各項目には線画のアイコンが出ます
- `Code.gs` と `Report.html` は同じです

渡すときは、生徒のデータが入っていない「配布用テンプレート」のスプレッドシートに `dist/` のコードを貼っておき、その「コピーを作成」のリンクを渡します。

## コードを貼り直す手順（いま使っているスプレッドシートで）

1. スプレッドシートを開き、**拡張機能 → Apps Script**
2. `コード.gs`（または `Code.gs`）の中身をすべて消し、このフォルダの [`Code.gs`](Code.gs) を貼り付ける
3. `Index` の中身をすべて消し、このフォルダの [`Index.html`](Index.html) を貼り付ける
4. 左の「ファイル」の **＋ → HTML** で、名前を **`Report`** にしたファイルを作り、このフォルダの [`Report.html`](Report.html) を貼り付ける（2回目からは中身の貼りかえだけ）
5. 💾 保存
6. 右上の **デプロイ → デプロイを管理** → 鉛筆マーク
   - **バージョン：新バージョン**
   - **次のユーザーとして実行：自分**　← ここを「アクセスしているユーザー」から変える
   - **アクセスできるユーザー：（学校のドメイン）内の全員**
   - **デプロイ** を押す。許可を求められたら、自分のアカウントで許可する
   - ※「次のユーザーとして実行」が変えられないときは、**デプロイ → 新しいデプロイ** で同じ設定のものを作ります。この場合は生徒用URLが変わるので、Classroom などのリンクも貼りかえてください。
7. スプレッドシートを再読み込みし、メニュー **探究アセスメント → 版を確認** を押す。生徒画面のいちばん下に出る「版」と同じなら完了です。

## スプレッドシートの共有を先生だけにする

デプロイを「自分」に変えたら、生徒にシートを共有する必要はありません。

1. スプレッドシート右上の **共有**
2. 生徒（または生徒が入っているグループ）を削除する
3. 「一般的なアクセス」が「（学校名）」や「リンクを知っている全員」になっていたら **制限付き** にする
4. 集計を見るほかの先生は、ここに個別に追加する

> 生徒がこれまでシートを開けた状態だった場合、その間に回答が書きかえられていないか、念のため「回答」シートの変更履歴（ファイル → 変更履歴）を確認してください。

## 生徒名簿を登録する（年度ごと）

1. メニュー **探究アセスメント → 👥 生徒名簿を設定する**（今年度の「生徒名簿_2026」のようなシートが作られます）
2. A列に出席番号、B列に氏名を貼り付ける（Excel や校務システムの表からコピーでOK）
   - 出席番号の書き方：高校1年2組15番 → `1215`、中学1年B組15番 → `1B15`
   - C列のふりがな、D列のGoogleアカウントは空でもかまいません
   - **D列にGoogleアカウント（メールアドレス）を入れておくと**、生徒が開いたときに番号と名前が自動で入ります。ほかの生徒の番号では送れなくなるので、なりすましも防げます
3. もう一度 **生徒名簿を設定する** を押すと、番号の書き方の誤りや重なりがないか確かめられます
4. 4月になると、新しい年度の名簿シートが作られます。前の年度のシートはそのまま残り、前の年度のレポートに使われます

名簿がない年度は、これまでどおり生徒が名前を手で入力します。

## レポートを作る・印刷する

メニュー **探究アセスメント → 🖨 レポートを作る・印刷する** を押すと、レポートの画面が開きます。上で年度・種類・クラスなどを選ぶと、下のプレビューがすぐ変わります。

| タブ | 選ぶもの | 出てくるもの |
|---|---|---|
| ① クラス集計 | 実施回（1回分 or すべて）、クラス（いくつでも）、学年全体・学校全体を並べるか | 21項目×クラスの平均表（色つき）、カテゴリー別の棒グラフ、クラスごとのひとことまとめと高い項目・低い項目 |
| ② 学年・クラスの推移 | 学年ごと／クラスごと（クラスを選ぶ）、表示する値（総合・3カテゴリー） | 折れ線グラフ、カテゴリー別の小さいグラフ、数値の表（各回の回答者数、最初→最新の差） |
| ③ クラスの生徒の変容 | クラス、表示する値（総合・3カテゴリー・1項目・21項目すべて） | 名簿の番号順の一覧表。実施回ごとの値、最初→最新の差（▲▼）、推移の小グラフ、クラス平均。「21項目すべて」では1回分の21項目一覧と、前の回とくらべた▲▼ |
| ④ 生徒個人の成長 | クラス、生徒（1人 or クラス全員）、クラス平均も載せるか | 1人1ページ。変化のまとめの文章、総合・3カテゴリーの推移グラフ、21項目×実施回の表と最初→最新の差 |

**🖨 印刷する・PDFで保存する** を押すと印刷画面が出ます。PDFにするときは「送信先」で **PDFに保存** を選びます。印刷画面が出ないときは **別のタブで開いて印刷する** を使ってください。

- 推移のグラフは、変化が見えるように縦軸を拡大しています（グラフの右上に範囲を書いています）
- 名簿にない出席番号の回答は、③の表の最後に「（名簿外）」として出ます。番号の打ちまちがいなら「回答」シートのC列を直してください

## 実施回を登録する

1. メニュー **探究アセスメント → 実施回を設定する**（初回は「実施回」シートが作られます）
2. A列に実施回の名前を書き、B列にチェックを入れる
   - チェックが入っている回だけ、生徒画面の選択肢に出ます。終わった回はチェックを外します
   - 受付中の回が1つだけなら、生徒画面では最初から選ばれた状態になります
   - チェックが1つもなければ、これまでどおり生徒がタイトルを自由に入力します
3. 生徒が画面を開き直すと反映されます

すでにたまっている回答のタイトルがばらばらなときは、「回答」シートのE列（タイトル）を同じ名前に直してからレポートを作ると、同じ回として集計されます。

## 気をつけること

- **一斉送信の上限**：「実行ユーザー：自分」では、先生のアカウントでプログラムが動きます。Google の制限で、同時に動けるのは約30件までです。40人が同じ瞬間に送信すると一部が「未送信」になることがありますが、生徒画面の「過去の記録 → 未送信の記録を教師に送信」で送り直せます（同じ記録が2重に入ることはありません）。
- **名簿の名前の確認**：名簿にGoogleアカウントを書いていない生徒は、出席番号を入れると名簿の名前が表示されます。ほかの生徒の番号を入れると、その生徒の名前が見えることになります。気になる場合は、名簿のD列にアカウントを入れてください（入れた生徒の名前は本人にしか表示されません）。
- **生徒の端末の記録**：生徒画面の「過去の記録」は、その端末のブラウザに残っている記録です。共有の端末を使うときは、生徒ごとに Google アカウントでログインし直してください。
