# 授業の出欠（教務手帳）

授業ごとの欠席を、**Chromebook・PC で生徒を押すだけ** で記録するしくみです。記録は Google スプレッドシートの **教務手帳** のシートに、日付の列と「欠」でたまっていきます。

- 日付は自動（今日）。講座を押す → 欠席の生徒を押す → 「教務手帳に書きこむ」
- **座席表**（写真から作った見やすい表）と **名列** のどちらからでも押せます（1画面に両方出ます）
- 名前の横に **欠課時数** と **割合**（欠課時数 ÷ 年間時数）。**20%・25%・30%・50%** をこえると色が変わります
- 教務手帳は **直接直してOK**（あとから欠席扱いでないとわかったら、「欠」を消すだけ）
- 後日の入力も、その日付の位置に **日付順** に入ります
- 期間を指定して、**何コマ休んだか** を出せます

```
┌ 出欠をとる ───────────────────────────────────────┐
│ 📅 10/9（金） ◀ [2026/10/09] ▶   [1-1 英語コミュⅠ] [1-2 論理表現Ⅰ]   │
├────────────────────────┬──────────────────┤
│  座席表（写真から作った見やすい表）    │ 名列                             │
│  ┌───┬───┬───┐                 │  1 青木 さくら     欠0 0.0%      │
│  │ 01   │ 02   │ 03   │← 押すと「欠」  │  3 上野 ゆい  [欠] 欠19 18.1%    │
│  │青木  │石田  │上野  │                 │  5 大川 ひなた     欠25 23.8%    │
│  └───┴───┴───┘                 │  …                               │
├────────────────────────┴──────────────────┤
│ 欠席 1人 ・ 出席 35人                         [ 教務手帳に書きこむ ] │
└──────────────────────────────────────────┘
```

## スプレッドシートに貼る作業（最初の1回だけ・10分）

### 1. スプレッドシートを作って、プログラムを貼る

1. Google ドライブで **新しいスプレッドシート** を作り、名前を付ける（例：「授業の出欠 2026年度」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 次の **4つのファイル** を作って、このフォルダの中身をそれぞれ貼り付ける

   | Apps Script での名前 | 作り方 | 貼る中身 |
   |---|---|---|
   | `コード.gs`（最初からある） | 中身を全部消して貼る | [`Code.gs`](Code.gs) |
   | `Take` | ファイルの「＋」→ **HTML** → 名前に `Take` | [`Take.html`](Take.html) |
   | `Setup` | 同上 | [`Setup.html`](Setup.html) |
   | `Period` | 同上 | [`Period.html`](Period.html) |

   ※ HTML の名前は `.html` を付けずに入力します（自動で付きます）。大文字・小文字も同じに（`Take`・`Setup`・`Period`）。
   ※ GitHub のファイルを開いたら、右上の「コピー」ボタン（Copy raw file）で全部コピーできます。
4. 💾（保存）を押す

### 2. 許可する

1. スプレッドシートのタブに戻って **再読み込み**（F5）→ 上のメニューに **「📋 出欠」** が出ます
2. 「📋 出欠」→「⚙ 初期設定（名簿・講座・単位数）」を押す → 許可の画面が出たら、自分のアカウントを選んで **「許可」**
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（名前）に移動」→「許可」）
   - 座席表の写真をドライブに保存するため、ドライブの許可も求められます
3. もう一度「📋 出欠」→「⚙ 初期設定」を押す

> ためしたいときは、「📋 出欠」→「その他」→「お試しデータを入れる」（2クラス・20人の名簿と、講座・出欠が入ります）。

### 3. 初期設定（「⚙ 初期設定」の画面で）

1. **① 名簿**：Excel・校務システムの名簿から、生徒の行をまとめてコピーして貼る →「読み取って確認する」→「登録する」
   - 学籍番号（`1101`＝1年1組1番）でも、学年・組・番号が別の列（`1 1 1`、`1年1組 1番`）や1つのマス（`1年1組1番`、`1-1-1`）でも読み取ります。CSV（`,` 区切り）も貼れます
   - ふりがな・性別の列があってもかまいません（性別の列は使いません）。同じ学籍番号の行が2つあると、あとの行は「読み取れない行」になります
   - クラス（`1-1`）と番号（出席番号）は学籍番号から自動で入ります
2. **② 講座・単位数**：持っている授業を1つずつ登録（講座名・対象のクラス・**単位数**）
   - 登録すると、講座ごとに **教務手帳のシート** ができます（シートの名前＝講座名）
   - 「1-1 英語コミュⅠ」「1-2 英語コミュⅠ」のように **授業×クラス** で登録すると、シートもクラスごとに分かれます
   - 年間時数＝単位数 × 35（「設定」タブで変えられます）
3. **③ まとめて入力**（学期の途中から使い始めるとき・メニューの「📝 まとめて入力（使い始める前の欠課）」からも開けます）：講座を選んで、生徒ごとに **それまでの欠課時数** を入れる → 保存
   - 教務手帳の「それ以前の欠課」の列に入り、欠課時数と割合に足されます
   - Enter・↓ で次の生徒、↑ で前の生徒に移ります

## 授業のたびに

「📋 出欠」→ **「✋ 出欠をとる」**（大きめの画面が開きます。開いたままシートもさわれます）

1. 上の **講座** を押す（日付は今日が入っています）
2. **欠席した生徒を押す** → 赤くなります（もう一度押すと元に戻ります）
   - 左の座席表の写真の上の名前でも、右の名列でも、どちらで押してもOK
3. **「教務手帳に書きこむ」** → 教務手帳のシートに日付の列ができ、欠席した生徒のマスに「欠」が入ります

- 同じ日にもう一度開くと「記録ずみ」になり、直して上書きできます
- 2時間続きの授業は「2時間続き（2コマ分として書きこむ）」にチェック。教務手帳には2列入り、曜日の段に「続き」と入ります。あとで開くと「2・3コマ目（2時間続き）」として2列まとめて直せます（「1コマずつ直す」で1列ずつも直せます）。教務手帳には2列入り、曜日の段に「続き」と入ります。あとで開くと「2・3コマ目（2時間続き）」として2列まとめて直せます（「1コマずつ直す」で1列ずつも直せます）
- 同じ日に別のコマがあるときは「＋ この日にもう1コマ記録する」

### 後日、休んだ日の分を入れるとき

上の日付を **◀ ▶** か日付の欄で、その日に変えてから同じように押して書きこみます。教務手帳には **日付の順の位置** に列が入ります（後から入れても順番はくずれません）。「今日にもどす」で今日に戻ります。

## 座席表（写真から見やすい表を作って押す）

出欠をとる画面の左の **「📷 座席表を登録する」**（2回目からは「✏ 座席表を直す・撮り直す」）

1. **📷 カメラで撮る**（PC・Chromebook のカメラが起動します）→ 座席表の全体が入るように写して「撮る」
   - または **🖼 写真のファイルを選ぶ**／写真を貼り付け（Ctrl + V）・ドラッグ
   - 横向きなどのときは「↻ 回転」
2. **🔤 名前を自動で読み取る** → 写真の中の **出席番号（2けたの数字）** と **名前** を読み取り、名列と照合して、ボタンを自動で置きます
   - 1クラスの講座では、出席番号と名前の両方で照合します（合同授業は番号が重なるので名前だけ）
   - 読めなかった生徒は、表のマスを1つずつ読み直します
   - それでも残った生徒は、右の名列で選んで（黄色の枠）→ 写真の上のその席を押すと置けます
   - ずれているボタンはドラッグで動かせます。外すときは名列の ×
3. 写真の下に **できあがる座席表（見やすい表）** の見本が出ます。教卓が写っていれば「教卓：写真の上／写真の下」を選ぶ（表に「教卓」が出ます）
4. **座席表を保存する**

保存すると、出欠をとる画面の左に **見やすい表**（ボタンの位置から行と列をそろえて作り直した座席表）が出ます。各席に出席番号・名前・欠課時数と割合（色つき）が出て、押すと赤くなり「欠」になります。

- **↕ 向きを変える**：上下・左右をさかさまにします（教卓から見た向き ⇔ 生徒から見た向き）
- **写真** に切りかえると、写真の上で押すこともできます
- 席がえをしたら「✏ 座席表を直す・撮り直す」→「📷 撮り直す」→「🔤 名前を自動で読み取る」
- 同じクラスの講座（例：1-1 の英語コミュⅠと論理表現Ⅰ）は、同じ座席表を使います
- 写真は、スプレッドシートと同じフォルダの「出欠_座席表の写真」に保存されます
- 座席表を登録しなくても、名列から押して記録できます

## 教務手帳のシート

```
1-1 英語コミュⅠ     単位数 3  年間時数 105
クラス 番号 学籍番号 氏名        欠課時数 割合   それ以前の欠課 ┃ 9/18 9/25 10/2 10/9
1-1    3    1103     上野 りく      21   20.0%     18           ┃  欠   欠   欠
```

- **欠課時数** ＝ それ以前の欠課 ＋「欠」の数（シートの数式で数えます）
- **割合** ＝ 欠課時数 ÷ 年間時数。20%以上 黄／25% 橙／30% 赤／50% 濃い赤（名前と割合のマスの色）
- マスを直接直してかまいません。**インフルエンザなどで欠席扱いにならなかったとわかったら、そのマスの「欠」を消すだけ** で、合計・割合・色が直ります
- 講座ごとに年間時数を変えたいときは、G1（年間時数）に数を直接入れます

## 期間を指定して集計

「📋 出欠」→ **「🔎 期間を指定して集計」**

- 講座（すべて／1つ）と期間（今週＝月曜から今日まで・今月・先月・1学期・2学期・3学期・年度、または日付）を選ぶと、生徒ごとに **その期間に休んだコマ数** が出ます
- 「休んだ生徒だけ出す」でしぼりこみ、「📄 シートに書き出す」で「期間集計」シートに出して印刷できます
- 「まとめて入力」した「それ以前の欠課」は日付がないので、期間の集計には入りません

## 設定（「⚙ 初期設定」→「設定」タブ）

| 項目 | 最初の値 |
|---|---|
| 1単位あたりの年間授業時数 | 35 |
| 色を変える割合（%） | 20, 25, 30, 50 |
| 学期の区切り（期間集計のボタン） | 1学期 4/1-7/31, 2学期 8/1-12/31, 3学期 1/1-3/31 |

## うまくいかないとき

- **カメラが起動しない**：アドレスバー右のカメラのマークで「許可」にしてから、もう一度押してください。それでもだめなときは、カメラのアプリで撮ってから「写真のファイルを選ぶ」で選んでください
- **名前を自動で読み取れない**：読み取りの部品をインターネットから読み込みます（はじめての時は少し時間がかかります）。座席表に影や斜めの写りが少ないように撮ると、よく読めます。読めなかった生徒は手で置けます
- **シートを消してしまった**：「📋 出欠」→「その他」→「シートを作り直す」
- **色や数式がおかしくなった**：「📋 出欠」→「その他」→「教務手帳の色・数式を整える」
- **プログラムを貼り直したのに変わらない**：出欠をとる画面の名列のいちばん下の「版」で、新しくなったか確かめられます

## ファイル

| ファイル | 内容 |
|---|---|
| `Code.gs` | メニュー、教務手帳への書きこみ、名簿・講座・座席表の保存、期間集計 |
| `Take.html` | 出欠をとる画面（座席表と名列・座席表の登録） |
| `Setup.html` | 初期設定の画面（名簿・講座と単位数・まとめて入力・設定） |
| `Period.html` | 期間集計の画面 |
| `appsscript.json` | Apps Script の設定（clasp で入れる場合に使う。手で貼る場合は不要） |

名前の自動読み取りには [Tesseract.js](https://github.com/naptha/tesseract.js)（Apache License 2.0）を使っています（画面から読み込むだけで、このリポジトリには入っていません）。
