# 授業の出欠

授業ごとの出欠（欠課・遅刻・早退・公欠・出停・忌引）を、**スマホで名前をタップするだけ** で記録するしくみです。記録は Google スプレッドシートにたまり、学期ごとの欠課時数もすぐに出せます。

- 全員「出席」から始まるので、**休んだ・遅れた生徒だけ押せばOK**
- 時限を押すと、**先週の同じ曜日・時限の講座** に「いつもの」印が付きます（時間割を覚える）
- 名前の横に **これまでの欠課・遅刻の回数** が出ます。欠課時数が「注意する数」をこえると赤
- 名簿は **Excel や校務システムの表をコピーして貼るだけ**（課題提出バーコード管理と同じ読み取り方）
- 電波が切れて保存できなくても、入力した出欠はスマホに残ります（次に開いたときに「保存されていない出欠があります」）

```
┌ 授業の出欠 ──────────┐      ┌ ◀戻る 1-1 英語コミュⅠ ──┐
│ 日付  ◀ 10/9 金 ▶        │      │ [欠課][遅刻][早退][公欠]…│
│ ① 時限  1 [2] 3 4 5 6     │  →   │  1 青木 そうた    出席    │
│ ② 講座                    │      │  3 上野 りく 欠3  [欠課]  │
│  [1-1 英語コミュⅠ いつもの]│      │  6 加藤 あおい    [遅刻]  │
│  [1-2 英語コミュⅠ]         │      │ 出席 9/10 欠課1 遅刻1     │
│ 🗂記録の一覧 📊集計 ⚙設定 │      │ [      保存する       ]   │
└─────────────┘      └─────────────┘
```

## はじめに（1回だけ・10分）

### 1. スプレッドシートにプログラムを入れる

1. Google ドライブで **新しいスプレッドシート** を作り、名前を付ける（例：「授業の出欠 2026年度」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 次の2つのファイルを作って、このフォルダの中身をそれぞれ貼り付ける

   | Apps Script での名前 | 作り方 | 中身 |
   |---|---|---|
   | `コード.gs`（最初からある） | 中身を全部消して貼る | [`Code.gs`](Code.gs) |
   | `Index` | ファイルの「＋」→ **HTML** → 名前に `Index` | [`Index.html`](Index.html) |

   ※ HTML の名前は `.html` を付けずに入力します（自動で付きます）。`I` は大文字です。
4. 💾 保存

### 2. スマホで開けるページとして公開する

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 左の ⚙ から「種類の選択」で **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（生徒の個人情報が入るので、自分だけが開けるようにします）
3. **デプロイ** を押す。アクセスの承認を求められたら、自分のアカウントを選んで許可する
   （「このアプリは Google で確認されていません」と出たら「詳細」→「（名前）に移動」→「許可」）
4. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を、スマホに送ってブックマーク（ホーム画面に追加）する
   - あとから URL を見たいときは、スプレッドシートのメニュー **「📋 出欠」→「📱 出欠ページを開く」**
   - スマホのブラウザは、学校の Google アカウントでログインしておきます

> プログラムを貼り直したときは、「デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。ページのいちばん下の「版」で、反映されたか確かめられます。

### 3. 名簿と講座を登録する（出欠ページの「⚙ 設定」から）

1. **👥 名簿を貼り付ける**：Excel・校務システムから生徒の行をまとめてコピー → 貼り付け →「読み取って確認する」→「登録する」
   - 学籍番号（`1101`）でも、学年・組・番号が別の列（`1 1 1`、`1年1組 1番`）でも読み取ります
   - 学籍番号から、クラス（`1-1`）と番号が自動で入ります
2. **＋ 講座を追加**：自分の授業ごとに 1つずつ
   - 講座名（例：`1-1 英語コミュⅠ`）
   - 対象のクラス（ボタンで選ぶ。合同授業なら複数）
   - 選択授業など、クラスの一部だけのときは「個別の生徒」に学籍番号を「,」区切りで
   - 注意する欠課時数（例：年間35時間で3分の1をこえると未履修なら `11`）。これ以上になると赤で表示

お試ししたいときは、スプレッドシートのメニュー「📋 出欠」→「お試しデータを入れる」（2クラス・20人と、3週間分の記録が入ります）。

## 授業のたびに

1. 出欠ページを開く（日付は今日になっています。◀ ▶ で前後の日も記録できます）
2. **① 時限** を押す → **② 講座** を押す
3. 上のボタンで区分（**欠課**・遅刻・早退・公欠・出停・忌引）を選んで、**その生徒の名前を押す**
   - もう一度押すと「出席」に戻ります
   - 授業メモ（例：L5 本文）も残せます
4. **保存する**

- 記録ずみの授業には ✓ が付きます。押すと開いて、直したり消したりできます
- 同じ日・時限・講座をもう一度保存すると、前の記録が書きかわります（二重にはなりません）
- 過去の授業は「🗂 記録の一覧」から講座ごとに見られます

## 集計（📊）

講座と期間（「1学期」「2学期」「3学期」「年度」のボタン、または日付）を選ぶと、生徒ごとの **欠課時数・欠課・遅刻・早退・公欠・出停** が出ます。「📄 シートに書き出す」で「集計（講座名）」シートができ、印刷や成績処理に使えます。

| 列 | 中身 |
|---|---|
| 欠課時数 | 欠課の数（設定で「遅刻・早退を ○回で欠課1」にしたときは、その分も足す） |
| 公欠・出停 | 欠課時数には数えません |
| 出席すべき時数（シートのみ） | 授業の回数 − 公欠 − 出停・忌引 |

「⚙ 設定」で変えられること：1日の時限の数（最初は6）、遅刻・早退を何回で欠課1にするか（最初は数えない）、学期の区切り（前期・後期でもOK。例：`前期 4/1-9/30, 後期 10/1-3/31`）

## シートについて

| シート | 中身 |
|---|---|
| 名簿 | 学籍番号・クラス・番号・氏名・ふりがな。転出した生徒は「除外」に ✓ |
| 講座 | 講座名・対象（クラスや学籍番号を「,」区切り）・注意する欠課時数 |
| 授業記録 | 1回の授業が1行（日付・時限・講座・人数・授業メモ） |
| 出欠 | 出席以外だった生徒が1人1行（出席の生徒は記録しません） |
| 設定 | 時限の数・遅刻の数え方・学期の区切り |

- シートを直接直してもかまいません。「出欠」の区分は `欠課`／`遅刻`／`早退`／`公欠`／`出停・忌引` のどれかで書きます（`欠席` も欠課として読みます）
- 1年ごとに新しいスプレッドシートを作るのがおすすめです（ページに出る「これまでの回数」は今年度（4月〜3月）の分です）

## よくある質問

- **ほかの先生と同じファイルを使える？** → スプレッドシートを「編集者」で共有し、デプロイの設定を「次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**」「アクセスできるユーザー：**（学校）内の全員**」にします。各先生は最初に1回「許可」を押します。「授業記録」の「記録者」に、記録した先生のメールアドレスが入ります
- **2時間続きの授業は？** → それぞれの時限で記録します（2回目は同じ生徒を押すだけ）
- **生徒が開いてしまうことは？** → 「アクセスできるユーザー：自分のみ」にしていれば、URL を知っていても先生以外は開けません

## ファイル

| ファイル | 内容 |

| `appsscript.json` | Apps Script の設定（clasp で入れる場合に使う。手で貼る場合は不要） |
