# AI英会話れんしゅう

Chromebook で1つのリンクを開くと、**左に「お助け表現集と手順」、右に ChatGPT（音声モードで会話）** が並ぶ英会話練習ページです。

- 生徒用：https://aoyagi01-oss.github.io/aoao/ （いつも同じURL。Classroom には最初に1回貼るだけ）
- 先生用：https://aoyagi01-oss.github.io/aoao/teacher.html

## しくみ

```
先生用ページ（teacher.html）──「生徒に公開する」──▶ Google スプレッドシート「AI英会話 教材リスト」
                                                        │（Apps Script がつなぐ）
生徒用ページ（index.html）◀──── 今日の教材を読み込む ──┘
   └─「AIと英会話をはじめる」→ ChatGPT が右半分に開き、先生のプロンプトで会話が始まる
```

- **今日の教材**：スプレッドシートのうち、公開日が今日以前（または空欄）の行で**いちばん下の行**。公開日を先の日付にしておけば、予約公開になります。
- ChatGPT は他のページの中に埋め込めない（iframe 不可）ため、別ウィンドウを右半分に開く方式にしています。
- スプレッドシートを直接書き換えても反映されます（行を消す、公開日を変えるなど）。

## 先生の手順（授業ごと）

1. 先生用ページを開く
2. ひな形か「これまでの教材」から始めて、内容を直す
3. 「📢 生徒に公開する」を押す

## 最初に1回だけ：スプレッドシートとつなぐ

Google ドライブの **「AI英会話 教材リスト」** というスプレッドシート（作成済み）を使います。

1. そのスプレッドシートを開き、メニューの **拡張機能 → Apps Script** を押す
2. 最初から入っている文字（`function myFunction() {…}`）をすべて消し、このリポジトリの [`apps-script/Code.gs`](apps-script/Code.gs) の中身を貼り付ける
3. 5行目あたりの `const PASSWORD = 'ここを合言葉に変える';` の `ここを合言葉に変える` を、自分だけの合言葉に書き換える（先生用ページで公開するときに使います）
4. 上の 💾（保存）を押す
5. 右上の **デプロイ → 新しいデプロイ** を押す
   - 左の ⚙ から「種類の選択」で **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（選べない場合は、学校のドメイン内の全員）
   - **デプロイ** を押す。アクセスの承認を求められたら、自分のアカウントを選んで許可する
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーし、[`config.js`](config.js) の `API_URL = ''` の `''` の中に貼る

> Apps Script の中身を後で変えたときは、「デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。

## スプレッドシートとつながる前でも使える方法

先生用ページのいちばん下「この教材だけのURLを作る」で作ったURLには、教材の内容がすべて入っています。これを Classroom に貼れば、スプレッドシートがなくても使えます。

## 生徒側の注意

- 初回はポップアップのブロックが出ることがあります → アドレスバー右のマークから「常に許可」
- マイクの使用を「許可」
- ウィンドウがうまく並ばないときは、ChatGPT のウィンドウで **Alt + ]**（右半分）、このページで **Alt + [**（左半分）
