# AI英会話れんしゅう

Chromebook で1つのリンクを開くと、**左に「お助け表現集と手順」、右に ChatGPT（音声モードで会話）** が並ぶ英会話練習ページです。

## しくみ

- `teacher.html`（先生用・教材メーカー）
  フォームに場面・役・レベル・目標表現を入れると、ChatGPT へのプロンプトと**生徒用URL**を自動で作ります。
  教材の内容はすべてURLの中に入るので、**ファイルの編集やアップロードは不要**です。
- `index.html`（生徒用）
  「AIと英会話をはじめる」を押すと、ChatGPT が画面の右半分に開きます。
  先生のプロンプトが送信された状態で新しい会話が始まるので、生徒は 🎙 音声モードを押して話すだけです。
  - ChatGPT は他のページの中に埋め込めない（iframe 不可）ため、別ウィンドウを右半分に開く方式にしています。

## 先生の手順（授業ごと）

1. `teacher.html` を開く
2. ひな形を選ぶ、またはフォームを書き換える
3. 「生徒用URLをコピー」→ Google Classroom の資料・課題に「リンク」として貼る

生徒用URLを `teacher.html` で開き直すと（生徒ページ下の「先生用」リンクからも可）、同じ内容から修正・複製できます。

## 最初に1回だけ：公開設定（GitHub Pages）

1. GitHub のこのリポジトリ → **Settings → Pages**
2. Source: *Deploy from a branch*、Branch: `main`（または作業ブランチ） / `/ (root)` → Save
3. 数分後に `https://aoyagi01-oss.github.io/aoao/teacher.html` で開けます
   - 公開リポジトリである必要があります（無料プランの場合）。教材の中身はURLにあるので、リポジトリに個人情報は含まれません。

## 生徒側の注意

- 初回はポップアップのブロックが出ることがあります → アドレスバー右のマークから「常に許可」
- マイクの使用を「許可」
- ウィンドウがうまく並ばないときは、ChatGPT のウィンドウで **Alt + ]**（右半分）、このページで **Alt + [**（左半分）

## 共通のお助け表現・ひな形を変えたいとき

`lessons.js` の `HELP_PHRASES`（全教材共通の表現）と `PRESETS`（ひな形）を編集してください。
