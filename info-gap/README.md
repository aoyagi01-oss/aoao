# インフォギャップ配信

インフォメーションギャップ練習のために、**A役の生徒とB役の生徒に、それぞれ別のスライドを同時に見せる** しくみです。先生が「次へ」を押すと、全員が一斉に次のページに進みます。A役にはA用、B役にはB用のページが出ます。

- 生徒用：https://aoyagi01-oss.github.io/aoao/info-gap/ （いつも同じURL。Classroom には最初に1回貼るだけ）
- 先生用：https://aoyagi01-oss.github.io/aoao/info-gap/teacher.html

```
先生：A用とB用の Google スライドを2つ作る
        │ 先生用ページで「スライドを準備する」
        ▼
Apps Script（先生の Google アカウント）が、全ページを画像にしてドライブに保存
        │
        ├─ 先生用ページ：「次へ ▶」で「いま何ページ目か」だけを送る
        ▼
生徒用ページ：最初に A か B を選ぶ → 自分の役割のページだけが出る
```

- 画像は生徒の Chromebook に前もって読み込んでおくので、「次へ」を押すと1〜3秒で全員が切り替わります。
- 授業中に送るのは「いま何ページ目か」だけなので、40人以上でも軽く動きます。
- 画面共有（[`gamen-kyoyu`](../gamen-kyoyu/README.md)）とは別のしくみです。両方そのまま使えます。

## スライドの作り方

1. Google スライドを **2つ** 作ります。「A用」と「B用」です。
2. **同じ番号のページが、同じ場面** になるようにそろえます（A用の3ページ目とB用の3ページ目が、同じ問題の「A が知っていること」と「B が知っていること」）。
3. スライドは先生のアカウントで開けるものなら、共有の設定はいりません（生徒には画像だけが届きます）。
4. 1つのスライドは **40ページまで** です。アニメーションや動画は出ません（1ページ＝1枚の画像になります）。

> ページ数がちがってもかまいません。少ない方は、最後のページのあと「このページはありません」と出ます。

## 先生の手順（授業ごと）

1. 先生用ページを開き、合言葉と、A用・B用のスライドの URL を入れて **📥 スライドを準備する**（1ページ2秒くらいかかります。前の日に準備しておいてもかまいません）
2. 生徒に生徒用ページを開かせ、**A か B を選ばせます**
3. **次へ ▶** で1ページ目を出し、あとは「次へ」「前へ」で進めます（キーボードの → ← や、プレゼン用のリモコンでも進められます）

| ボタン | はたらき |
|---|---|
| ◀ 前へ ・ 次へ ▶ | A役もB役も、同じ番号のページに進む・戻る |
| 🙈 生徒の画面をかくす | 全員の画面が「先生の方を見てください」になる。もう一度押すと戻る |
| ⇄ AとBを入れかえる | A役にB用、B役にA用のページが出る。役割を交代して2回目をするときに使う |
| ⏮ はじまる前に戻す | 生徒には「はじまるまで待ってください」と出る |

> 先生用ページの下に、**A役・B役の生徒にいま見えている画面** が並んで出ます。スライドを準備しなおすと、前の画像は消え、生徒の画面は「はじまる前」に戻ります。

## 生徒の見方

- 開くと「あなたの役割をえらんでください」と出るので、**A** か **B** を押します。左上に自分の役割が出ます。
- まちがえたときは、下の **役割を変える** で選びなおせます（タブを閉じると、次に開いたときにまた選びます）。
- 画面共有と同じように、**ダブルタップ・2本指のピンチ・＋－ボタン** で手元で拡大できます。ページが変わると元の大きさに戻ります。

## 最初に1回だけ：Apps Script を用意する

画面共有（gamen-kyoyu）とは **別の Apps Script** を作ります。

1. Google ドライブで **新規 → その他 → Google Apps Script** を押す（名前は「インフォギャップ配信」など）
2. 最初から入っている文字をすべて消し、このフォルダの [`Code.gs`](Code.gs) の中身を貼り付ける
3. `const PASSWORD = 'ここを合言葉に変える';` の `ここを合言葉に変える` を、自分だけの合言葉に書き換える
4. 💾（保存）を押す
5. 上の関数の選択で `setup` を選んで **▶ 実行** を押し、アクセスを許可する（「確認されていません」と出たら「詳細」→「（名前）に移動」→「許可」）。スライド・ドライブ・外部への接続を使う許可を求められます
6. 右上の **デプロイ → 新しいデプロイ**
   - ⚙ の「種類の選択」で **ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（選べない場合は、学校のドメイン内の全員）
   - **デプロイ** を押す
7. 表示された **ウェブアプリの URL**（`https://script.google.com/…/exec`）をコピーし、[`config.js`](config.js) の `API_URL = ''` の `''` の中に貼る

> `Code.gs` を後で変えたときは「デプロイ → デプロイを管理 → ✏ 編集 → バージョン：新バージョン → デプロイ」で反映します（URL は変わりません）。

## 気をつけること

- **最初は少人数で試してください**。とくに「スライドを準備する」は、学校の Google アカウントの設定によっては動かないことがあります。そのときは先生用ページに出たメッセージを教えてください。
- スライドの画像は、先生のドライブの **「インフォギャップ配信の画像（自動で作られます）」** フォルダに保存されます。準備しなおすと前の画像はゴミ箱に移ります。
- 生徒用URLを知っている人は、準備したスライドを見られます（合言葉が要るのは先生の操作だけ）。個人情報はスライドに入れないでください。
- 生徒は自分で A・B を選ぶので、相手の役割に切り替えて見ることもできます。ペアの約束として伝えてください。
