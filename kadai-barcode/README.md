# 課題提出バーコード管理

課題の提出を **バーコードリーダーで「ピッ」と読むだけ** で記録し、Google スプレッドシートに **業務手帳の形** でたまっていくしくみです。

- 先生がさわるのは右側に出る **「ホーム」画面だけ**（シートを直接さわらなくても使えます）
- 名簿は **Excel や校務システムの表をコピーして貼るだけ**
- 課題の登録は **教科・課題名も空欄でOK**、締切は「明日」「1週間後」ボタン
- 提出物は **クラスや番号の順番がばらばらでもOK**。読んだ瞬間に業務手帳のマスに日付が入る
- バーコードは **A4 に1人1本の短冊**。裁断機で1回切ると1人分、生徒が右から切ってはる
- 課題・教科が変わっても、**進級しても同じバーコード** を使い続けられる
- **コピーして配れば、ほかの先生もすぐ使える**

---

## 先生向け：使い方（3分）

### 0. 自分用のコピーを作る

配られたリンク（末尾が `/copy`）を開き、「コピーを作成」を押します。自分のドライブに、プログラムごとコピーされます。

開いたら、上のメニュー **「📋 課題提出」→「🏠 ホーム」** を押します。
はじめての1回だけ Google の確認画面が出ます → 自分のアカウントを選んで **「許可」**（「このアプリは確認されていません」と出たら「詳細」→「（名前）に移動」→「許可」）。そのあと、もう一度メニューの「ホーム」を押します。

右側に出る **ホーム** から、すべての操作ができます。

```
┌ ホーム ─────────────────┐
│ 📷 読み取る                  │ ← 毎日使う
│ ➕ 課題を登録する            │
│ 最近の課題                   │
│  数学 ワーク 34/39人 [📷読む]│
│ 見る・印刷する               │
│  📒提出状況   📝未提出者     │
│  🤒欠席・配慮 📊集計         │
│  🏷バーコード 👥名簿         │
│ ▸ はじめの準備（1/4）        │
└──────────────────┘
```

### 1. はじめの準備（1回だけ）

ホームの「はじめの準備」にそって進めます。終わった項目には ✓ が付きます。

1. **👥 名簿を貼り付ける**
   Excel・校務システム・名簿ファイルから、生徒の行をまとめてコピー → 枠に貼り付け → 「読み取って確認する」→「登録する」。
   列の順番はそのままでOK。学籍番号（`1101`）でも、学年・組・番号が別の列（`1 1 1`、`1年1組 1番`）でも読み取ります。ふりがなの列があれば、それも読み取ります。
2. **🏷 バーコードを印刷する**
   A4 に1人1本の短冊が12本並びます（左に学籍番号と氏名、右にバーコード3つ）。
   **横の太い点線で裁断機を1回下ろすと、その生徒専用の短冊**になります。生徒は右側の細い点線から1つずつ切って、ノートやファイルにはります（ノーカットのシール用紙を使うと便利）。
   切り取ったバーコードにも、学籍番号と名前が入っています。
   印刷は **A4・倍率100%**（「ページに合わせる」は切る）で。

### 2. ふだん

1. **➕ 課題を登録する**：教科・課題名（どちらも空欄でもOK）、クラス（ボタンで選ぶ。選ばなければ全員）、締切（「明日」「1週間後」などのボタン）→ **「登録して、読み取りへ」**
2. **📷 読み取る**：読み取り欄をクリックしてから、提出物のバーコードをピッ・ピッ・ピッ
   - 順番はばらばらでOK。ピッ＝提出、ピピッ＝締切後の提出、ブー＝まちがい（未登録・2回目）
   - 画面に「提出 34／対象 39」と **まだ出していない生徒の名前** が出ます
   - 下のボタンで読み取りのモードを切りかえられます：**✓ 提出**（ふつう）／ **△ 未完成**（中身ができていない提出物）／ **✕ 取り消し**
   - まちがえたら「直前の1件を取り消す」
   - バーコードを忘れた生徒は、学籍番号（`1101`）を打って Enter でもOK
   - あとから出しに来た生徒も、ホームの課題の「📷 読む」から同じように読めます
3. **📒 提出状況（業務手帳）**：左に学籍番号・氏名、上に教科・課題名・締切日、マスに提出した日付
   - 黄＝遅れて提出、青＝欠席・配慮で期限内、△＝未完成、赤＝締切を過ぎて未提出、免＝免除、－＝対象外のクラス
   - 右はしに提出数・提出率・期限内提出率・未提出の数
   - ホームの「表示の設定」で、自分の教科・クラスだけにしぼったり、日付のかわりに ○ にしたりできます
4. **📝 未提出者・提出のお願い**：課題とクラスを選ぶと、先生用の未提出者リストや、生徒に配る「提出のお願い」（1人1枚、切って渡せる）ができ、PDF でまとめて印刷できます

### 3. 遅れ・欠席・配慮のあつかい

| あつかい | どうなる | 業務手帳 | 提出率 | 期限内提出率 |
|---|---|---|---|---|
| 期限内に提出 | ふつうの提出 | 緑・日付 | 数える | 数える |
| **遅れて提出** | 提出として認める。ただし期限内とは分ける | **黄**・日付（○モードは「遅」） | 数える | 数えない |
| **欠席で延長** | 休んだ日を登録すると、その期間にかかる課題は **休んだ日数（登校日）だけ、その生徒の締切が自動で延びる**。延びた締切までに出せば期限内 | **青**・日付 | 数える | 数える |
| **配慮** | その課題は、その生徒だけ「遅れても期限内あつかい」。未提出でも赤にしない | **青**・日付 | 数える | 数える |
| **免除** | その課題は、その生徒は出さなくてよい | 「免」 | 分母から外す | 分母から外す |
| **未完成**（使いたい先生だけ） | 出したが中身が未完成。**ふつうは未提出あつかい**（設定で「提出として数える」にもできる） | **△**（オレンジ） | 数えない（設定しだい） | 数えない |
| 未提出 | （その生徒の）締切を過ぎたら赤 | **赤** | 数えない | 数えない |

- **欠席の入れ方**：ホームの「🤒 欠席・配慮・免除」→ 学籍番号を打つ（名前でも、バーコードを読んでもOK。何人でも）→ 休んだ日（「今日」「昨日」ボタン）→ 理由（「かぜ」などのボタン、なくてもOK）→ 登録。朝の出欠のときにまとめて入れておくのがおすすめです
  - 例：10/2（金）締切の課題を、10/1（木）・10/2（金）に休んだ → その生徒の締切は 10/6（火）。業務手帳は 10/6 までは赤にならず、未提出者リストや「提出のお願い」にも「締切 10/6（延長）」と出ます
  - 休んだ日数は、課題を出した日〜締切日のあいだの平日で数えます（出した日が空欄なら締切の1週間前から）。祝日は数えに入るので、気になるときは「配慮」を使ってください
- **遅れて出してきたとき**：読み取り画面に「この生徒は締切後の提出です。欠席などの事情がありますか？」と出ます。**「欠席などのため配慮する」を押すと、その場で期限内あつかい**。押さなければ遅れのまま
- **配慮・免除**：保健室登校・別室・家庭の事情・長期欠席・入院など、欠席日だけでは決められないときに、課題と生徒を選んで登録します
- **未完成の提出物**（使わなくてもかまいません）：読み取り画面の下のボタンを **「△ 未完成」** にして、中身ができていない提出物のバーコードを読みます。
  - その生徒は「未完成」になり、業務手帳では △、未提出者リストには「未完成（再提出）」、提出のお願いには「（未完成・出し直し）」と出ます
  - 直して出し直してきたら、ふつうの「✓ 提出」で読むだけ → 「再提出（完成）」として記録され、出し直した日が提出日になります
  - 数え方はホームの「表示の設定」→「未完成（△）の数え方」で選べます：**未提出あつかい（出し直させる・最初の設定）** ／ 提出として数える（期限内には数えない）
  - 未完成を区別しない先生は、何もしなくてOK（ボタンを「✓ 提出」のまま使うだけ）。読んだあとで未完成とわかったものを未提出に戻したいだけなら「✕ 取り消し」でも同じです
- 登録したものは「登録したもの」の一覧からいつでも取り消せます（データは「欠席・配慮」シートにたまります）
- 「集計」シートと業務手帳の右はしに **提出率** と **期限内提出率** の両方が出るので、評価にはどちらを使うかを学校・教科で決められます

### 4. 進級したら

新しい名簿を **そのまま「名簿の貼り付け」に貼るだけ**。同じ名前の生徒は学籍番号・クラス・番号だけが新しくなり、**バーコードは刷り直さずに使えます**（バーコードの中身は3年間変わらない「生徒ID」で、学籍番号は印字されているだけです）。

## 準備する人向け：ひな形を作る（最初の1回だけ・1人でOK）

1. Google ドライブで **新しいスプレッドシート** を作り、名前を付ける（例：「課題提出バーコード（ひな形）」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 次のファイルを作って、このフォルダの中身をそれぞれ貼り付ける

   | Apps Script での名前 | 作り方 | 中身 |
   |---|---|---|
   | `コード.gs`（最初からある） | 中身を全部消して貼る | [`Code.gs`](Code.gs) |
   | `Home` | ファイルの「＋」→ **HTML** → 名前に `Home` | [`Home.html`](Home.html) |
   | `Scan` | 同上 | [`Scan.html`](Scan.html) |
   | `Task` | 同上 | [`Task.html`](Task.html) |
   | `Roster` | 同上 | [`Roster.html`](Roster.html) |
   | `Excuse` | 同上 | [`Excuse.html`](Excuse.html) |
   | `Print` | 同上 | [`Print.html`](Print.html) |
   | `Select` | 同上 | [`Select.html`](Select.html) |
   | `JsBarcode` | 同上 | [`JsBarcode.html`](JsBarcode.html)（バーコードを描く部品。長い1行です） |

   ※ HTML の名前は `.html` を付けずに入力します（自動で付きます）。大文字・小文字も同じに。
4. 💾 保存 → スプレッドシートに戻って **再読み込み** → メニュー「📋 課題提出」→「🏠 ホーム」（許可画面が出たら許可）
5. 「その他」→「お試しデータを入れる」で動きを確かめる
6. 確かめたら **「その他」→「配布用のひな形にする（データを全部消す）」**
7. 共有 → 「リンクを知っている全員（校内）」を **閲覧者** にしてリンクをコピーし、末尾の `/edit…` を **`/copy`** に書きかえて先生たちに配る

   ```
   https://docs.google.com/spreadsheets/d/（ID）/copy
   ```

> 学年や教科の先生どうしで **1つのスプレッドシートを共有して使う** こともできます（同時に読み取っても記録は混ざりません）。生徒の個人情報を扱うので、共有範囲は校内の必要な先生だけにしてください。

## バーコードリーダーについて

- 一般的な **USB（または Bluetooth）の「キーボードとして入力する」タイプ** で動きます
- 読み取りのあとに **Enter（改行）** を送る設定にしてください（多くの機種は最初からそう）
- バーコードの形式は **Code128**（予備の方法でシートに作ったものは Code39）。ほとんどのリーダーは最初から両方読めます
- 日本語入力がオンのままでも読めるようにしてありますが、うまくいかないときは半角英数にしてください

## よくある質問

- **課題が変わったら、バーコードを刷り直す必要は？** → ありません
- **提出物がクラスごちゃまぜ・番号ばらばらでも大丈夫？** → 大丈夫です。読んだバーコードの生徒の行に記録されます
- **データはどこにたまる？** → 「提出記録」シートに、1回の読み取りが1行（日時つき）でたまっていきます。「提出状況」（業務手帳）はそこから自動で作られます。記録を直すときは「提出記録」の行を直接消す・直す → ホームの「📒 提出状況」を押す
- **印刷画面が開かない** → 「バーコード印刷」の画面の「別のタブで開く」から印刷。それでもだめなら「その他」→「バーコードをシートに作る」
- **シートを消してしまった** → 「その他」→「シートを作り直す」
- **生徒数・課題数が多くても大丈夫？** → 学年全体（数百人）×年間の課題程度なら問題なく動きます
