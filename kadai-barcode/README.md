# 課題提出バーコード管理

課題の提出を、**バーコードリーダーで「ピッ」と読むだけ**で記録し、Google スプレッドシートで提出状況・提出率を一元管理するしくみです。

- 生徒1人に1つのバーコード（中身は**生徒IDだけ**）。どの課題の提出かは読み取り画面で選ぶので、**課題・教材・教科が変わっても、学年が上がっても同じバーコードを使い続けられます**
- 教科・クラスは自由に設定（1人の先生が複数教科・複数クラスを持っていても OK）
- 未提出者リスト、生徒に渡す「提出のお願い」をまとめて印刷
- 提出状況（生徒×課題の表）、課題別・クラス別・教科別の提出率を自動集計
- スプレッドシートを**コピーして配れば、ほかの先生もそのまま使えます**（プログラムも一緒にコピーされます）

## 全体の流れ

```
 生徒名簿 ──▶ バーコードを印刷（シール／名簿型）── 1回だけ
 課題一覧 ──▶ 課題を書く（教科・課題名・対象クラス・締切日）── 課題ごと
 読み取り画面 ──▶ 課題を選んで、ピッ・ピッ・ピッ … ──▶ 提出記録
                                                        │
          ┌─────────────────────────────────────────┘
          ▼
  提出状況（○ 遅 未）／ 集計（提出率）／ 未提出者リスト・提出のお願い（印刷）
```

## シートの構成

| シート | 内容 | だれが書く |
|---|---|---|
| 使い方 | 手順のまとめ | 自動 |
| 設定 | 印刷物の見出し、集計に出す教科・クラスのしぼりこみ、「提出のお願い」の文 | 先生 |
| 生徒名簿 | 生徒ID（バーコード）・クラス・番号・氏名・ふりがな・除外 | 先生（IDは自動） |
| 課題一覧 | 課題ID・教科・課題名・対象クラス・出した日・締切日・メモ ／ 対象・提出・遅れ・未提出・提出率 | 先生（IDと右側の数字は自動） |
| 提出記録 | 読み取った記録（1回の「ピッ」が1行） | 自動（手で直してもよい） |
| 提出状況 | 生徒×課題の表。○＝提出、遅＝締切後に提出、未＝未提出（赤は締切切れ）、－＝対象外 | 自動 |
| 集計 | 課題別・クラス別・教科別の提出率 | 自動 |
| 印刷_… | 印刷用に毎回作り直すシート | 自動 |

## 最初に1回だけ：スプレッドシートを用意する

1. Google ドライブで **新しいスプレッドシート** を作り、名前を付ける（例：「課題提出管理 2026」）
2. メニューの **拡張機能 → Apps Script** を開く
3. 次の5つのファイルを作って、このフォルダの中身をそれぞれ貼り付ける

   | Apps Script での名前 | 作り方 | 中身 |
   |---|---|---|
   | `コード.gs`（最初からある） | 中身を全部消して貼る | [`Code.gs`](Code.gs) |
   | `Scan` | ファイルの「＋」→ **HTML** → 名前に `Scan` | [`Scan.html`](Scan.html) |
   | `Print` | 同上 → `Print` | [`Print.html`](Print.html) |
   | `Select` | 同上 → `Select` | [`Select.html`](Select.html) |
   | `JsBarcode` | 同上 → `JsBarcode` | [`JsBarcode.html`](JsBarcode.html)（バーコードを描く部品。長い1行です） |

   ※ HTML ファイルの名前は `.html` を付けずに入力します（自動で付きます）。大文字・小文字も同じにしてください。
4. 💾（保存）を押し、スプレッドシートのタブに戻って **再読み込み**
5. メニューに **「課題バーコード」** が出るので、**「初期設定（シートを作る）」** を押す
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで **許可**
     （「このアプリは Google で確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」→「許可」）
   - データは自分のスプレッドシートの中だけに保存され、外には送られません

> 試しに動かしたいときは **「お試しデータを入れる」** を押すと、架空の生徒6人と課題3つが入ります（あとで行ごと消してください）。

## 使い方

### 1. 生徒名簿をつくる（年度はじめに1回）

- 「生徒名簿」シートに **クラス・番号・氏名** を貼り付けます。校務システムから出した名簿をそのまま貼ってかまいません
- **生徒ID は空欄で OK**。読み取りや集計のときに自動で `100001` のような6けたの番号が付きます
  - 学籍番号を使いたいときは、ID の列に学籍番号を入れておけばそれを使います（数字・英字のみ）
- クラスの書き方（`1-1` / `1年1組` など）は自由ですが、**課題一覧の「対象クラス」と同じ書き方**にそろえてください
- 転出した生徒などは「除外」に ✓ を入れると、集計や未提出者リストに出なくなります
- **一度付いた生徒IDは変えないでください**（バーコードが使えなくなります）。クラス替えのときは「クラス」「番号」だけを書き換えれば、同じバーコードをそのまま使えます

### 2. バーコードを印刷する（年度はじめに1回）

メニュー **「バーコードを印刷する（生徒・課題）」**

| 印刷するもの | 使い方 |
|---|---|
| 生徒のバーコード（3列） | 切ってノート・ファイル・提出用の袋などにはる。「1人あたり◯枚」で複数枚も印刷できる。シール用紙に印刷してもよい |
| 名簿型 | 先生の手元用。バーコードをはっていない提出物は、この名簿のバーコードを読む |
| 課題のバーコード | 読み取り画面でこのバーコードを読むと、その課題に切りかわる（マウスを使わずに続けて回収できる） |

- 「印刷する」で印刷画面が出ないときは **「別のタブで開く」** から印刷してください
- それでもうまくいかないときは、メニュー **「バーコードをシートに作る」**（予備の方法。バーコード用フォント Code39 を使い、PDF で印刷）

### 3. 課題を登録する（課題を出すたび）

「課題一覧」シートに1行ずつ書きます。

| 列 | 書き方 |
|---|---|
| 課題ID | 空欄のまま（自動で `K001` のように付く） |
| 教科 | 自由（国語、数学、総合、学活 …） |
| 課題名 | 自由 |
| 対象クラス | `1-1,1-2` のようにカンマ区切り。**空欄なら全員** |
| 出した日・締切日 | 日付。締切日の翌日以降の提出は「遅れ」になる。締切日が空欄なら遅れにならない |

### 4. 回収する（読み取り）

1. メニュー **「読み取りを始める」** → 右側に読み取り画面が出る
2. いちばん上で **課題を選ぶ**（課題のバーコードを読んでも切りかわる）
3. 読み取り欄をクリックしてから、提出物のバーコードを次々に読む

| 音・色 | 意味 |
|---|---|
| ピッ（緑） | 提出を記録 |
| ピピッ（黄） | 締切後の提出、または対象外クラスの生徒（記録はする） |
| ブー（赤） | 登録されていないバーコード／すでに提出済み（2回目は記録しない） |

- 画面に **提出数・提出率・未提出の生徒** がその場で出ます。回収しながら「あと◯◯さん」と声をかけられます
- 間違えたら **「直前の1件を取り消す」**、または **「取り消しモード」** にして取り消したい生徒を読む
- ⚠ 読み取り欄からカーソルが外れていると、シートのセルに数字が入ってしまいます。画面が赤くなったら読み取り欄をクリックしてください
- 後から出してきた生徒も、同じように読めば OK（日時が記録され、締切後なら「遅」になります）

### 5. 提出を促す・集計する

- **「提出状況・集計を更新」**：「提出状況」「集計」シートと、「課題一覧」の右側（対象・提出・遅れ・未提出・提出率）が新しくなります
  - 「提出状況」の提出率は、締切が過ぎた課題（と締切なしの課題・提出済みの課題）で計算します
  - 「設定」で、表に出す教科・クラスをしぼれます（例：教科に `数学` と書けば数学だけ）
- **「未提出者リスト・提出のお願いを作る」**：課題とクラスを選んで
  - **未提出者リスト（先生用）**：課題ごとに未提出の生徒の一覧
  - **提出のお願い（生徒に配る）**：生徒ごとに、出していない課題をまとめた紙（✂ で切って渡せる）
  - できたら **「PDFで開いて印刷する」** を押す（まとめて一括印刷）

## ほかの先生に配る

**方法A（おすすめ）**：上の手順で作ったスプレッドシートの生徒名簿・課題一覧・提出記録を空にして「ひな形」として保存し、共有リンクの末尾を `/edit…` から **`/copy`** に変えて配ります。

```
https://docs.google.com/spreadsheets/d/（スプレッドシートのID）/copy
```

開いた先生には「コピーを作成」ボタンが出て、プログラムごと自分のドライブにコピーされます（ひな形は「閲覧者」で共有すれば OK）。コピーした先生は最初の1回だけ Google の許可画面で「許可」を押します。

**方法B**：この README の「最初に1回だけ」の手順を、各先生がそれぞれ行う。

> 1つのスプレッドシートを学年や教科の先生どうしで共有して使うこともできます（同時に読み取っても記録が混ざらないようにしてあります）。生徒の個人情報を扱うので、共有範囲は校内の必要な先生だけにしてください。

## バーコードリーダーについて

- 一般的な **USB（またはBluetooth）の「キーボードとして入力する」タイプ** で動きます
- 読み取りのあとに **Enter（改行）** を送る設定にしてください（多くの機種は最初からそうなっています）
- 生徒のバーコードは **Code128**（予備の方法でシートに作ったものは **Code39**）。ほとんどのリーダーは最初から両方読めます
- 日本語入力がオンのままでも読めるようにしてありますが、うまくいかないときは半角英数（日本語入力オフ）にしてください
- 印刷が薄い・小さいと読みにくくなります。プリンタの品質を「きれい」にし、倍率を縮小しないで印刷してください

## よくある質問

- **課題が変わったら、バーコードを刷り直す必要は？** → ありません。バーコードは生徒IDだけなので、ずっと同じものを使えます
- **次の年度は？** → スプレッドシートをコピーし、課題一覧と提出記録を空にします。生徒名簿は「クラス」「番号」を新しくするだけで、バーコードはそのまま使えます
- **提出記録を手で直したい** → 「提出記録」シートの行を直接消したり追加したりしてかまいません（課題ID・生徒IDの列が合っていれば集計されます）。直したら「提出状況・集計を更新」を押してください
- **生徒数・課題数が多くても大丈夫？** → 学年全体（数百人）×年間の課題程度なら問題なく動きます
